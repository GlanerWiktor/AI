# AXONORA — statyczny szablon strony AI

Responsywna strona zbudowana wyłącznie w HTML, CSS i JavaScript. Zawiera interaktywne demonstratory AI oraz osobną podstronę z portfolio zrealizowanych projektów. Nie wymaga kompilacji, API ani zależności.

## Uruchomienie

Otwórz `index.html` bezpośrednio w przeglądarce albo uruchom dowolny prosty serwer lokalny.

## Publikacja na GitHub Pages

1. Utwórz repozytorium i skopiuj do niego zawartość tego folderu.
2. Wypchnij pliki na gałąź `main`.
3. W GitHub wybierz **Settings → Pages**.
4. W sekcji **Build and deployment** wybierz **Deploy from a branch**, gałąź `main` i folder `/ (root)`.

## Personalizacja

- Nazwa, treści i sekcje: `index.html`
- Kolory, typografia i layout: zmienne na początku `styles.css`
- Projekty, treści modali i logika demonstratorów: `projectData`, `templates` oraz `bindDemo` w `script.js`
- Portfolio projektów: `case-studies/index.html`, `case-studies/catalog.css` i `case-studies/catalog.js`
- Adres e-mail: wyszukaj `hello@axonora.ai`
- Obraz hero: `assets/ai-lattice-hero.png`

Wszystkie nazwy marek, wyniki i opisy projektów są przykładowe i należy zastąpić je prawdziwymi informacjami przed publikacją komercyjną.
